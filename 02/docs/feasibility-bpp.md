# مستند امکان‌سنجی و منشور پروژه

## عنوان پروژه
سامانه رزرو آنلاین بلیط سفر و تورهای گردشگری

---

# ۱. منشور پروژه (Project Charter)

### عنوان پروژه
طراحی و پیاده‌سازی سامانه رزرو آنلاین بلیط سفر و تورهای گردشگری

### مدیر پروژه
دانشجوی انجام‌دهنده پروژه

### حامی مالی پروژه
دانشجو (تأمین‌کننده هزینه‌های احتمالی پروژه)

### اهداف کلان پروژه

1. ایجاد بستری آنلاین برای جستجو و رزرو بلیط سفر.
2. فراهم کردن امکان مشاهده و انتخاب تورهای گردشگری.
3. ایجاد امکان ثبت‌نام و ورود کاربران به سامانه.
4. ساده‌سازی فرایند رزرو بلیط و تورهای گردشگری.
5. طراحی پنل مدیریت برای کنترل اطلاعات کاربران، بلیط‌ها و تورها.
6. افزایش سرعت و سهولت دسترسی کاربران به خدمات گردشگری.

### شرح مختصر پروژه

هدف از اجرای این پروژه طراحی سامانه‌ای است که کاربران بتوانند از طریق آن بلیط سفر و تورهای گردشگری را جستجو، مشاهده و رزرو کنند. همچنین مدیر سامانه امکان مدیریت اطلاعات و بررسی رزروها را خواهد داشت.

---

# ۲. بیانیه محدوده پروژه (Project Scope Statement - PSS)

در این بخش فعالیت‌ها و امکاناتی که در محدوده پروژه قرار دارند و مواردی که خارج از محدوده پروژه هستند مشخص می‌شوند.

## ۲-۱. موارد داخل محدوده پروژه (In-Scope)

موارد زیر در محدوده اجرای پروژه قرار دارند:

1. طراحی صفحه اصلی سامانه.
2. طراحی و پیاده‌سازی بخش ثبت‌نام کاربران.
3. طراحی و پیاده‌سازی بخش ورود کاربران.
4. ایجاد امکان جستجوی بلیط سفر.
5. نمایش اطلاعات مربوط به بلیط‌ها و مسیرهای سفر.
6. نمایش تورهای گردشگری و اطلاعات آن‌ها.
7. ایجاد امکان رزرو آنلاین بلیط.
8. ایجاد امکان رزرو تورهای گردشگری.
9. طراحی پنل مدیریت سامانه.
10. مدیریت اطلاعات کاربران و رزروها.
11. تست سامانه و رفع خطاهای احتمالی.

## ۲-۲. موارد خارج از محدوده پروژه (Out-of-Scope)

موارد زیر در محدوده فعلی پروژه قرار ندارند:

1. اتصال مستقیم به سیستم‌های واقعی شرکت‌های هواپیمایی و حمل‌ونقل.
2. خرید و صدور واقعی بلیط از شرکت‌های مسافرتی.
3. اتصال به درگاه پرداخت بانکی واقعی.
4. طراحی اپلیکیشن موبایل مستقل.
5. ارائه خدمات پشتیبانی شبانه‌روزی.
6. اتصال به سامانه‌های خارجی گردشگری.

# ۳. امکان‌سنجی اقتصادی (Economic Feasibility)

هدف از امکان‌سنجی اقتصادی بررسی هزینه‌ها و منافع اجرای پروژه است.

## ۳-۱. منافع ملموس (Tangible Benefits)

منافع ملموس شامل مزایایی هستند که می‌توان آن‌ها را از نظر مالی یا کمی اندازه‌گیری کرد.

| شماره | منفعت ملموس | توضیحات |
|---|---|---|
| ۱ | کاهش هزینه‌های اداری | کاهش نیاز به ثبت دستی اطلاعات رزروها |
| ۲ | کاهش هزینه نیروی انسانی | خودکارسازی بخشی از فرایند ثبت و پیگیری رزروها |
| ۳ | افزایش درآمد احتمالی | فراهم شدن امکان ارائه خدمات رزرو و دریافت کارمزد در صورت تجاری‌سازی سامانه |

## ۳-۲. منافع ناملموس (Intangible Benefits)

منافع ناملموس مزایایی هستند که ارزش آن‌ها به‌صورت مستقیم و مالی قابل اندازه‌گیری نیست.

| شماره | منفعت ناملموس | توضیحات |
|---|---|---|
| ۱ | افزایش رضایت کاربران | دسترسی آسان‌تر و سریع‌تر به خدمات سفر |
| ۲ | افزایش اعتبار و اعتماد | ایجاد تجربه کاربری بهتر و افزایش اعتماد مشتریان به سامانه |

## ۳-۳. هزینه‌های یک‌باره (One-Time Costs)

| شماره | نوع هزینه | توضیحات |
|---|---|---|
| ۱ | هزینه طراحی سامانه | طراحی صفحات و رابط کاربری |
| ۲ | هزینه توسعه نرم‌افزار | برنامه‌نویسی و پیاده‌سازی امکانات سامانه |
| ۳ | هزینه طراحی پایگاه داده | طراحی ساختار ذخیره‌سازی اطلاعات |
| ۴ | هزینه تست اولیه | بررسی عملکرد و رفع خطاهای سامانه |

## ۳-۴. هزینه‌های تکرارشونده (Recurring Costs)

| شماره | نوع هزینه | توضیحات |
|---|---|---|
| ۱ | هزینه میزبانی وب | هزینه استفاده از فضای سرور در صورت انتشار سامانه |
| ۲ | هزینه دامنه | تمدید سالانه نام دامنه |
| ۳ | هزینه نگهداری سامانه | به‌روزرسانی و رفع مشکلات احتمالی |
| ۴ | هزینه پشتیبانی | رسیدگی به مشکلات و درخواست‌های کاربران |

**نتیجه امکان‌سنجی اقتصادی:**

با توجه به اینکه پروژه در ابتدا به‌صورت دانشگاهی و آزمایشی اجرا می‌شود، می‌توان بخش زیادی از هزینه‌های اولیه را با استفاده از ابزارهای رایگان و منابع موجود کاهش داد. بنابراین اجرای اولیه پروژه از نظر اقتصادی امکان‌پذیر است.

# ۴. امکان‌سنجی فنی (Technical Feasibility)

امکان‌سنجی فنی با هدف بررسی توانایی اجرای پروژه از نظر فناوری، ابزارها و منابع فنی انجام می‌شود.

برای پیاده‌سازی این سامانه می‌توان از فناوری‌های متداول طراحی وب، زبان برنامه‌نویسی مناسب، پایگاه داده و ابزارهای مدیریت پروژه استفاده کرد.

## ۴-۱. ابزارها و فناوری‌های پیشنهادی

| شماره | ابزار یا فناوری | کاربرد |
|---|---|---|
| ۱ | HTML و CSS | طراحی صفحات وب |
| ۲ | JavaScript | ایجاد قابلیت‌های تعاملی |
| ۳ | زبان برنامه‌نویسی سمت سرور | پیاده‌سازی منطق سامانه |
| ۴ | MySQL | ذخیره و مدیریت اطلاعات |
| ۵ | GitHub | مدیریت کدها و مستندات پروژه |

## ۴-۲. جدول تحلیل عوامل ریسک فنی

در این بخش سه عامل اصلی ریسک فنی پروژه بررسی می‌شوند.

| عامل ریسک | وضعیت | سطح ریسک | راهکار کنترل |
|---|---|---|---|
| پیچیدگی فنی | پیاده‌سازی سیستم رزرو و مدیریت اطلاعات نیازمند دقت است. | متوسط | تقسیم پروژه به بخش‌های کوچک‌تر |
| اندازه پروژه | پروژه شامل بخش‌های مختلف مانند کاربران، بلیط‌ها، تورها و مدیریت است. | متوسط | برنامه‌ریزی و اولویت‌بندی وظایف |
| آشنایی با فناوری | یادگیری و استفاده از فناوری‌های موردنیاز ممکن است زمان‌بر باشد. | متوسط | مطالعه مستندات و استفاده از آموزش‌های معتبر |

## ۴-۳. نتیجه امکان‌سنجی فنی

با توجه به در دسترس بودن ابزارهای توسعه نرم‌افزار و فناوری‌های موردنیاز، اجرای این پروژه از نظر فنی امکان‌پذیر است.

همچنین با تقسیم پروژه به بخش‌های کوچک‌تر و برنامه‌ریزی مناسب می‌توان پیچیدگی‌های فنی را کنترل کرد.

# ۵. نتیجه‌گیری نهایی

با بررسی منشور پروژه، محدوده فعالیت‌ها، منافع و هزینه‌های اقتصادی و همچنین عوامل فنی و ریسک‌های احتمالی، مشخص می‌شود که طراحی و پیاده‌سازی سامانه رزرو آنلاین بلیط سفر و تورهای گردشگری برای یک پروژه دانشگاهی امکان‌پذیر است.

این پروژه با استفاده از ابزارها و فناوری‌های مناسب و مدیریت صحیح فعالیت‌ها می‌تواند در زمان تعیین‌شده اجرا و تکمیل شود.
